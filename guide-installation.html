Utiliser Galac6 sur téléphone, tablette et ordinateur

Galac6 s'utilise directement dans le navigateur, sur téléphone, tablette ou ordinateur, sans rien installer. Il suffit d'ouvrir le site et de se connecter.

Dans le navigateur

  1. Ouvrez galac6web.netlify.app dans votre navigateur (Safari, Chrome, Firefox ou Edge, dans une version récente).
  2. Créez un compte ou connectez-vous.
  3. C'est tout : Galac6 est prêt à être utilisé.
Ouvrir Galac6

Sur téléphone et tablette

Galac6 fonctionne dans le navigateur de l'iPhone, de l'iPad et des téléphones et tablettes Android. Pour le retrouver plus vite, vous pouvez ajouter un raccourci sur l'écran d'accueil :

  • iPhone et iPad (Safari) : touchez le bouton Partager, puis « Sur l'écran d'accueil ».
  • Android (Chrome) : touchez le menu en haut à droite, puis « Ajouter à l'écran d'accueil ».

Ce raccourci ouvre simplement Galac6 dans le navigateur.

Sur ordinateur

Sur Mac, Windows ou Linux, ouvrez Galac6 dans votre navigateur habituel. Aucun logiciel n'est à télécharger.

Galac6 s'utilise dans le navigateur, sans application à télécharger

Toutes les fonctionnalités de Galac6 sont accessibles depuis le navigateur, sur téléphone, tablette et ordinateur : il n'y a aucune application à télécharger. Pour ouvrir Galac6 d'un geste, ajoutez-le à l'écran d'accueil de votre téléphone ou de votre tablette, comme expliqué plus haut.
