Votre premier quiz Galac6, étape par étape

De la création de votre compte jusqu'à la lecture des résultats de votre classe. Les noms des boutons sont écrits en gras, tels que vous les verrez dans Galac6.

Créer mon compte professeur Le programme professeurs testeurs

Les six étapes

Sur ordinateur, tablette ou téléphone, dans un navigateur récent. Rien à installer.

  1. Créez votre compte 2 min

    Cliquez sur Créer mon compte professeur, puis remplissez le formulaire d'inscription : prénom, nom, adresse email et mot de passe. Si Galac6 vous demande si vous êtes « Un parent » ou « Un élève », choisissez Un parent : c'est le compte adulte de Galac6, celui qui donne accès à l'espace professeur. Cochez ensuite la case Je certifie être enseignant(e) et j'accepte les conditions d'utilisation.

    Galac6 vous envoie un email de confirmation : cliquez sur le lien qu'il contient.

    Une fois connecté, vous arrivez directement sur Mes classes : c'est votre espace professeur. Aucun code PIN n'est demandé. Si vous ajoutez plus tard un profil élève à votre compte, par exemple pour votre enfant, Galac6 vous demandera alors de choisir un code PIN pour protéger votre espace adulte.

  2. Créez une classe et obtenez son code d'invitation 1 min

    Dans Mes classes, cliquez sur Créer une classe. Donnez-lui un nom (par exemple « 4e B »), choisissez son niveau, puis cliquez sur Créer la classe. Si votre école n'est pas encore inscrite sur Galac6, votre classe est personnelle : vous pourrez demander plus tard à la rattacher à votre école.

    Ouvrez la classe, touchez le bouton des réglages (la roue dentée), puis Code d'invitation et affiche. Donnez ce code aux familles, ou imprimez l'affiche de la classe avec son QR code. Les parents saisissent le code dans Galac6 (Paramètres, puis Élèves) et leur enfant rejoint la classe.

  3. Demandez un quiz sur le chapitre en cours 3 min

    Dans votre classe, ouvrez l'onglet Devoirs, puis Quiz, et cliquez sur Créer une évaluation. La création se fait en quatre étapes : Contenu, Questions, Correction et Envoi.

    • Contenu : choisissez le type Quiz (vous pouvez aussi choisir Interrogation, Contrôle ou Devoir à la maison), puis la matière, le chapitre ou le thème, et un titre.
    • Questions : dans l'onglet Propositions, Galac6 propose une dizaine de questions vérifiées, faciles, moyennes et difficiles. Gardez celles qui vous conviennent. Dans l'onglet Assistant, écrivez ce que vous voulez, par exemple « 3 questions avec un piège », « Plus difficile » ou « Pour des élèves en difficulté ». Dans l'onglet Écrire, vous rédigez vos propres questions.

    La préparation des questions peut prendre une minute, parfois un peu plus. Galac6 ne garde que les questions dont il a pu vérifier la bonne réponse.

  4. Relisez et modifiez 2 min

    Relisez chaque question et sa bonne réponse. Cliquez sur Modifier pour changer un énoncé, un choix ou l'explication montrée aux élèves après le quiz. Galac6 vous signale une faute d'orthographe possible ou un doute sur une réponse, mais c'est vous qui décidez.

    Validez chaque question avec Valider, ou toutes d'un coup avec Tout valider. Le quiz ne peut être envoyé que lorsque toutes ses questions sont validées.

    L'étape Correction est facultative : sans réglage, Galac6 corrige avec ses règles habituelles. Vous pouvez y écrire vos propres consignes de correction : Galac6 les reformule en règles et ne les applique qu'avec votre accord.

  5. Donnez-le en devoir 1 min

    À l'étape Envoi, choisissez où se déroule le quiz :

    • À la maison, jusqu'à une date limite (facultative). Sans date limite, le quiz reste à faire jusqu'à ce que vous le retiriez.
    • En classe, avec une durée. Vous le lancez vous-même au début du cours. Pendant l'épreuve, le tuteur de Galac6 est coupé pour l'élève jusqu'à ce qu'il rende sa copie.

    Par défaut, un quiz n'est pas noté et l'élève voit sa correction dès qu'il a rendu sa copie. Si vous voulez une note, cochez Noté à cette étape, ou choisissez plutôt le type Interrogation à l'étape Contenu. Vous pouvez aussi choisir le moment où l'élève voit sa correction.

    Vérifiez le récapitulatif, puis cliquez sur le bouton d'envoi à votre classe (par exemple Envoyer à 4e B). Vos élèves voient le quiz en se connectant à Galac6.

  6. Lisez les résultats 1 min

    Dans l'onglet Devoirs, ouvrez le quiz envoyé. Vous y voyez :

    • le nombre d'élèves qui l'ont fait, et ceux qui sont en retard ;
    • les questions les plus ratées par la classe ;
    • la réussite par notion, avec les élèves en difficulté ;
    • la copie de chaque élève.

    Pour une évaluation notée, Galac6 propose une note pour chaque copie. Ouvrez une copie avec Voir la copie pour la relire ou changer une décision, puis cliquez sur Valider la note. Vous pouvez aussi valider en une seule fois toutes les copies que vous n'avez pas modifiées. Tant que vous n'avez pas validé, l'élève voit sa note comme provisoire.

    Si vous avez choisi de rendre la correction vous-même, cliquez sur Rendre les copies quand toute la classe a terminé : chaque élève voit alors sa correction.

    L'onglet Notions de la classe et la fiche de chaque élève (onglet Élèves) vous donnent une vue d'ensemble de leur travail.

Vous voulez d'abord essayer sans vos élèves ? Créez une classe de démonstration, préparez un quiz et regardez chaque écran sans rien envoyer. Pour utiliser Galac6 avec une vraie classe, parlez-en d'abord à votre direction.
Un écran ne correspond pas à ce guide, ou vous êtes bloqué ? Galac6 évolue chaque semaine pendant la beta. Écrivez-nous à hello@galac6.io : nous vous répondons et nous corrigeons le guide.
